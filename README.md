# منظومة متابعة المستخلصات — الواجهة

React + TypeScript + Vite، والبيانات والصلاحيات كلها في Supabase (RLS).

- التشغيل محليًا: `npm install && npm run dev`
- البناء: `npm run build` ← الملفات في `dist/` وبتترفع زي ما هي على أي استضافة ملفات ثابتة (GitHub Pages).
- المسارات بـ `#` (HashRouter) فمش محتاجة إعدادات سيرفر.
